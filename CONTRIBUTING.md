# Contributing to the Digital Herbarium

This repository is primarily an academic project, but improvements and corrections can be organized through GitHub.

## Adding a Plant Record

When adding a new plant:

1. Give it a unique record ID.
2. Add the common name.
3. Add the scientific name only when supported by the available evidence.
4. Add the botanical family.
5. Record the confidence level.
6. Add description, habitat and uses when available.
7. Add collection location and GPS data when available.
8. Add the photograph.
9. Do not invent missing information.

## Improving Identifications

If an identification is uncertain:

- Keep the uncertainty visible.
- Use a probable/provisional label where appropriate.
- Add supporting photographs or references.
- Prefer authoritative botanical references for verification.

## Website Changes

Keep the interface:

- Responsive
- Accessible
- Easy to navigate
- Consistent with the botanical archive theme

## Pull Requests

A useful pull request should explain:

- What was changed
- Why it was changed
- Which plant records are affected
- Whether photographs/data were added or modified
