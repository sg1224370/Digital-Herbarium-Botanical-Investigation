# Methodology

## 1. Observation

Plant specimens/observations are documented through photographs and field observations.

## 2. Record Creation

Every observation is assigned a unique record ID such as `P-001`, `P-002`, etc.

## 3. Identification

The available visual evidence is used to record the common name, scientific name and botanical family.

Where photographic evidence is insufficient for species-level identification, the record can remain at genus level or be marked probable/provisional.

## 4. Botanical Documentation

Where available, the record stores:

- Morphological description
- Habitat
- Uses
- Plant type
- Location
- GPS coordinates
- Collection date

## 5. Confidence Classification

Identification confidence is recorded so that users can distinguish stronger identifications from observations that require further verification.

## 6. Digital Presentation

The collected information is presented through:

- Search and filtering
- Plant cards
- Detailed record pages
- Botanical-family grouping
- Evidence-board visualization
- Field-data table
- GPS coordinate plotting

## 7. Verification

The website itself states that probable/provisional identifications should be verified with additional photographs or authoritative botanical references before final academic submission.

## 8. Future Data Architecture

For a larger collection, the current embedded data can be migrated into a separate JSON or database layer. Images can also be stored as individual files rather than embedded Base64 data.
