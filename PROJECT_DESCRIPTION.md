# Digital Herbarium — Project Description

## Overview

Digital Herbarium is an interactive botanical documentation website developed as an academic herbarium project.

The project converts plant observations and photographic records into a structured digital archive. Instead of keeping plant information only in a traditional physical herbarium format, the website allows users to explore botanical records through search, filters, family grouping, evidence visualization and field-data views.

## Problem

Traditional herbarium documentation can make it difficult to quickly search, compare and explore a large collection of plant observations. Important information such as photographs, identification, family, habitat, uses and collection location may also remain distributed across separate records.

## Proposed Solution

The Digital Herbarium organizes these observations into a single interactive archive.

Users can:

1. Search plant records.
2. Filter records by botanical family.
3. Filter by plant type.
4. Filter by identification confidence.
5. Sort records by different fields.
6. Open detailed plant profiles.
7. Explore botanical families.
8. View an evidence-board representation.
9. Review available field/collection data.
10. Inspect GPS information when it exists.

## Core Idea

The project follows a simple pipeline:

**Field Observation → Plant Identification → Data Documentation → Digital Archive**

## Scope

The current archive contains 18 botanical records. Information is preserved according to the supplied observations, and unavailable fields are not artificially filled.

## Important Academic Note

The website communicates identification confidence rather than presenting every identification as absolutely certain. Records described as probable or provisional should be independently verified with additional photographs or authoritative botanical references before final academic submission.
